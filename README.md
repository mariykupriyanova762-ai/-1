# Мои личные расходы

Учебный сайт для учёта трат: приветственная страница и приложение без сервера и сторонних библиотек.

## Как открыть

Откройте в браузере файл `index.html`.  
Приложение находится на странице `app.html`.

Данные хранятся только в этом браузере (`localStorage`).

## Что умеет приложение

- добавить расход: сумма, категория, дата;
- посмотреть список и удалить запись;
- увидеть итоги за сегодня и за последние 7 дней;
- переключить светлую и тёмную тему — выбор запоминается.

## Структура проекта

```text
index.html      приветственная страница
app.html        приложение учёта расходов
css/landing.css стили лендинга
js/theme.js     переключение темы на главной
LICENSE
README.md
```

Старый файл `мои расходы.html` оставлен как переход на `app.html`.

## Тема

Ключ в `localStorage`: `theme` (`light` или `dark`).  
Расходы хранятся в ключе `expenses`.
